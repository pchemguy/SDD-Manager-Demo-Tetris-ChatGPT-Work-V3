# Browser Tetris

A classic browser-based Tetris game under development. The [project brief](docs/dev/PROJECT.md) defines the accepted direction and selected gameplay scope. The [architecture proposal](docs/dev/ARCHITECTURE.md) defines the system boundaries for review. Application code and setup commands are not yet available.

Development uses [SDD Manager](SDD-MANAGER.md). See the [AI-assisted development disclosure](AI_DISCLOSURE.md).
