# Browser Tetris

A classic browser-based Tetris game under development. The [project brief](docs/dev/PROJECT.md) defines the accepted direction and selected gameplay scope. The accepted [architecture](docs/dev/ARCHITECTURE.md) defines system boundaries; the [component decomposition](docs/dev/DECOMPOSITION.md) is proposed for review. Application code and setup commands are not yet available.

Development uses [SDD Manager](SDD-MANAGER.md). See the [AI-assisted development disclosure](AI_DISCLOSURE.md).
